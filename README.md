# Entre Noses

Aplicativo Android de organização financeira para duas pessoas, em português brasileiro.

## Build
O GitHub Actions compila o APK de debug automaticamente ao enviar alterações para `main`. O APK poderá ser baixado em **Actions → Android APK → Artifacts** quando a compilação terminar.

## Estado do projeto
Estrutura Android inicial. A compilação e os testes precisam ser confirmados antes de considerar qualquer APK pronto para uso. Funcionalidades que dependam de sincronização em nuvem e autenticação precisam ser implementadas e configuradas antes da entrega final.

## Identidade
- Nome do aplicativo: Entre Noses
- Nome sob o ícone: Noses
- Idioma: português brasileiro
- Moeda e datas: R$ e DD/MM/AAAA
